**Nase** یک کامپایلر اسکیمای پایگاه داده است که با C# و .NET 10 توسعه داده می‌شود. این پروژه بخشی از دستورات DDL در SQL Server را تجزیه و اعتبارسنجی می‌کند و از ساختار پایگاه داده نمودار SVG می‌سازد.

Nase در حال حاضر در مرحلهٔ **MVP** قرار دارد و هدف آن پیاده‌سازی واقعی مراحل کامپایلر با معماری روشن و قابل توسعه است.

English | [فارسی](README.fa.md)

## قابلیت‌ها

- تحلیل واژگانی و تجزیهٔ دستورات پشتیبانی‌شدهٔ SQL Server
- اعتبارسنجی معنایی اسکیمای پایگاه داده
- تبدیل ساختار به نمایش میانی (IR)
- تولید نمودار اسکیمای پایگاه داده با فرمت SVG
- رابط خط فرمان
- تست‌های خودکار

## معماری

- `Nase.Core` — مدل‌های اصلی، توکن‌ها، ساختارهای نحوی و نمایش میانی.
- `Nase.FrontEnd` — تحلیل واژگانی، تجزیه و تحلیل معنایی.
- `Nase.SqlServer` — قابلیت‌های مرتبط با ساختارهای اختصاصی SQL Server.
- `Nase.Diagrams` — مدل نمودار پایگاه داده و تبدیل‌های مرتبط.
- `Nase.CodeGen.Svg` — تولید خروجی SVG.
- `Nase.Cli` — رابط خط فرمان و هماهنگی مراحل کامپایل.

## پیش‌نیازها

- نصب .NET 10 SDK
- ویندوز برای نسخهٔ مستقل فعلی

## نصب

### ویندوز — نسخهٔ آماده

۱. فایل `nase-win-x64.zip` را از صفحهٔ [انتشارهای گیت‌هاب](../../releases) دریافت کن.

۲. فایل ZIP را در یک مسیر دائمی، برای مثال `C:\Tools\Nase`، استخراج کن.

۳. مسیر نصب را به متغیر محیطی `PATH` ویندوز اضافه کن.

۴. یک ترمینال جدید باز کن و نصب را بررسی کن:

```powershell
nase --version
nase --help
```

حالا باید بتوانی دستور `nase` را از هر پوشه‌ای اجرا کنی.

> نسخهٔ مستقل منتشرشده به نصب جداگانهٔ Runtime دات‌نت نیاز ندارد.

### ساخت از سورس

اگر .NET 10 SDK نصب است، می‌توانی پروژه را از مخزن دریافت‌شده بسازی و اجرا کنی. برای شروع به بخش مربوط به اجرای پروژه مراجعه کن.

## شروع کار

مخزن را دریافت کن و سپس دستورات زیر را اجرا کن:

```powershell
dotnet restore .\Nase.sln
dotnet build .\Nase.sln
dotnet test .\Nase.sln
```

### اعتبارسنجی اسکیمای پایگاه داده

```powershell
dotnet run --project .\src\Nase.Cli -- check .\samples\basic-schema.sql
```

### تولید نمودار SVG

```powershell
dotnet run --project .\src\Nase.Cli -- diagram .\samples\basic-schema.sql -o .\output\schema.svg
```

فایل SVG تولیدشده را می‌توان در مرورگر یا نرم‌افزارهای سازگار با SVG مشاهده کرد.

## وضعیت پروژه

Nase یک MVP اولیه است. دستورات SQL پشتیبانی‌شده در حال حاضر محدود هستند و با توسعهٔ کامپایلر و تست‌ها گسترش خواهند یافت. نسخهٔ فعلی از تمام قابلیت‌های زبان SQL Server پشتیبانی نمی‌کند.

## اصول توسعه

- مستقل نگه‌داشتن نمایش میانی از زبان ورودی.
- جداسازی تجزیه از اعتبارسنجی معنایی.
- مستندکردن گرامر پشتیبانی‌شده.
- توسعهٔ تدریجی با مرزبندی روشن و بدون پیچیدگی غیرضروری.
- استفاده از تست‌های خودکار برای بررسی صحت عملکرد کامپایلر.
